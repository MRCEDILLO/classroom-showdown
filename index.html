The easiest way to start is to download the sample set and edit it in Excel or Google Sheets, then save it as CSV. It has a row for every kind of question: multiple choice, true or false, open, and questions with a picture, video, sound clip or YouTube link. The first row holds the column names. For a multiple-choice question, fill in at least options A and B and put the letter of the right option in the answer column. For an open question, leave A to D empty and type the answer itself in the answer column: after a buzz you mark it Correct or Incorrect. Explanation and topics are optional. To make words bold in a question, put two asterisks on each side, for example **LISTEN**.

Pictures, videos and sound: add an image column and type the file name on that question's row, for example q3.png or clip.mp4. It shows with the question. To show something when the answer is revealed, add an answer image column the same way. Put the CSV and the files in one folder, compress the folder into a zip file, and upload the zip.

Pictures can be PNG, JPG, GIF, WebP or SVG. Videos can be MP4 or WebM, and sound can be MP3, M4A or WAV. Keep video clips short so the zip stays small. You can also paste a YouTube link, or any web address starting with https://, instead of a file name. YouTube needs the internet in class and may be blocked on some school networks. The sample set links to pictures and clips stored on this website, so it works as a plain CSV with no zip.

Without a topics column, questions are put into columns of five in file order. The board holds up to 6 topics with 5 questions each.
