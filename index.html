The easiest way to start is to download the sample set and edit it in Excel or Google Sheets, then save it as CSV. The first row holds the column names. For a multiple-choice question, fill in at least options A and B and put the letter of the right option in the answer column. For an open question, leave A to D empty and type the answer itself in the answer column: after a buzz you mark it Correct or Incorrect. Explanation and topics are optional. To make words bold in a question, put two asterisks on each side, for example **LISTEN**.

Adding pictures: add an image column and type the picture's file name on that question's row, for example q3.png. Put the CSV and the pictures in one folder, compress the folder into a zip file, and upload the zip. PNG, JPG, GIF, WebP and SVG pictures work. You can also type a full web address (starting with https://) instead of a file name.

Without a topics column, questions are put into columns of five in file order. The board holds up to 6 topics with 5 questions each.
